## Known limitations of the figures

- Fig2a plots 63 proteins; four histones are labelled, the rest are unlabelled by design.
- Fig3 uses AlphaFold predicted structures; 81 of 88 Kpy sites map, the rest lie in proteins without a model or beyond the modelled fragment.
- Panel c of Fig3 excludes Kpy because only 81 sites map and the point is the annotation classes anyway.
